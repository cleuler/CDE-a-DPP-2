17  Comparação de Duas Médias

NoteCapítulo 21 - Comparação de Duas Médias

Este capítulo apresenta métodos estatísticos para comparar médias de dois grupos independentes, incluindo procedimentos t de duas amostras, testes de Welch e análise da igualdade de variâncias (ANOVA).

17.1 Introdução

A comparação de duas médias populacionais é um dos problemas mais comuns em estatística aplicada. Frequentemente, precisamos determinar se:

  • Dois tratamentos produzem resultados diferentes
  • Dois grupos têm características diferentes
  • Uma mudança de política teve efeito significativo
  • Dois métodos de ensino são igualmente eficazes

17.2 21.1 Configuração do Problema

17.2.1 Parâmetros e Estatísticas

Sejam duas populações com:

  • População 1: média μ₁ e desvio-padrão σ₁
  • População 2: média μ₂ e desvio-padrão σ₂

Amostras independentes: - Amostra 1: x̄₁, s₁, n₁ - Amostra 2: x̄₂, s₂, n₂

Objetivo: Fazer inferência sobre μ₁ - μ₂

17.2.2 Condições para Procedimentos t de Duas Amostras

ImportantCondições de Aplicação
  1. Dados: Duas amostras de observações quantitativas
  2. Independência: As observações em cada amostra são independentes
  3. Amostras independentes: As duas amostras são independentes entre si
  4. Normalidade: Cada população tem distribuição aproximadamente Normal, ou amostras grandes (n > 30 ou n > 40)

17.3 21.2 Teste t de Duas Amostras

17.3.1 Caso 1: Variâncias Populacionais Iguais (Teste t Pooled)

Quando σ₁ = σ₂ = σ (desconhecido), usamos o teste t pooled.

Estatística de teste: \[t = \frac{(\bar{x_1} - \bar{x_2}) - (\mu_1 - \mu_2)}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}\]

onde o desvio-padrão pooled é o desvio-padrão combinado: \[s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}}\]

Graus de liberdade: df = n₁ + n₂ - 2

Code
```{r teste-t-pooled}
# Exemplo prático: Eficácia de dois métodos de ensino jurídico

# Simulando dados realistas
set.seed(456)

# Método tradicional (aulas expositivas)
metodo_tradicional <- rnorm(20, mean = 72, sd = 12)

# Método inovador (aprendizagem ativa)
metodo_inovador <- rnorm(18, mean = 78, sd = 11)

# Criando dataset
ensino_juridico <- data.frame(
  nota = c(metodo_tradicional, metodo_inovador),
  metodo = factor(rep(c("Tradicional", "Inovador"), c(20, 18)))
)

# Estatísticas descritivas
stats_ensino <- ensino_juridico %>%
  group_by(metodo) %>%
  summarise(
    n = n(),
    media = mean(nota),
    dp = sd(nota),
    variancia = var(nota),
    .groups = "drop"
  )

print("Estatísticas por Método de Ensino:")
kable(stats_ensino,
      digits = 2,
      col.names = c("Método", "n", "Média", "Desvio-Padrão", "Variância")) %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

# Verificando igualdade de variâncias (Teste F)
var_test <- var.test(nota ~ metodo, data = ensino_juridico)
print("Teste F para Igualdade de Variâncias:")
print(var_test)

# Teste t pooled (assumindo variâncias iguais)
t_test_pooled <- t.test(nota ~ metodo, 
                       data = ensino_juridico, 
                       var.equal = TRUE,
                       alternative = "two.sided")

print("Teste t Pooled (Variâncias Iguais):")
print(t_test_pooled)

# Cálculos manuais para demonstração
n1 <- stats_ensino$n[2]  # Inovador
n2 <- stats_ensino$n[1]  # Tradicional
x1_bar <- stats_ensino$media[2]
x2_bar <- stats_ensino$media[1]
s1 <- stats_ensino$dp[2]
s2 <- stats_ensino$dp[1]

# Desvio-padrão pooled
sp <- sqrt(((n1-1)*s1^2 + (n2-1)*s2^2) / (n1 + n2 - 2))
cat("Desvio-padrão pooled (sp):", round(sp, 3), "\n")

# Erro padrão da diferença
se_diff <- sp * sqrt(1/n1 + 1/n2)
cat("Erro padrão da diferença:", round(se_diff, 3), "\n")

# Estatística t
t_stat <- (x1_bar - x2_bar) / se_diff
cat("Estatística t:", round(t_stat, 3), "\n")

# Graus de liberdade
df <- n1 + n2 - 2
cat("Graus de liberdade:", df, "\n")

# Valor p (bilateral)
p_valor <- 2 * pt(abs(t_stat), df, lower.tail = FALSE)
cat("Valor p:", round(p_valor, 4), "\n")

# Visualização
p_ensino <- ggplot(ensino_juridico, aes(x = metodo, y = nota, fill = metodo)) +
  geom_boxplot(alpha = 0.7, width = 0.6) +
  geom_jitter(width = 0.2, alpha = 0.6, size = 2) +
  stat_summary(fun = mean, geom = "point", 
               shape = 23, size = 4, fill = "white", stroke = 1.5) +
  labs(title = "Comparação das Notas por Método de Ensino",
       subtitle = paste("Teste t pooled: t =", round(t_stat, 2), 
                       ", p-valor =", round(p_valor, 4)),
       x = "Método de Ensino", 
       y = "Nota Final",
       caption = "Losango branco = média") +
  scale_fill_manual(values = c("lightcoral", "lightblue")) +
  theme(legend.position = "none")

print(p_ensino)
```

17.3.2 Caso 2: Variâncias Populacionais Diferentes (Teste de Welch)

Quando σ₁ ≠ σ₂, usamos o teste t de Welch (mais robusto):

Estatística de teste: \[t = \frac{(\bar{x_1} - \bar{x_2}) - (\mu_1 - \mu_2)}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}\]

Graus de liberdade combinado (fórmula de Welch-Satterthwaite): \[df = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}}\]

Code
```{r teste-welch}
# Exemplo: Tempo de processamento de dois tribunais

set.seed(789)

# Tribunal A (mais consistente)
tribunal_a <- rnorm(25, mean = 45, sd = 8)

# Tribunal B (mais variável) 
tribunal_b <- rnorm(22, mean = 40, sd = 18)

processamento <- data.frame(
  tempo = c(tribunal_a, tribunal_b),
  tribunal = factor(rep(c("Tribunal A", "Tribunal B"), c(25, 22)))
)

# Estatísticas descritivas
stats_tribunal <- processamento %>%
  group_by(tribunal) %>%
  summarise(
    n = n(),
    media = mean(tempo),
    dp = sd(tempo),
    variancia = var(tempo),
    cv = sd(tempo)/mean(tempo),  # Coeficiente de variação
    .groups = "drop"
  )

print("Estatísticas por Tribunal:")
kable(stats_tribunal,
      digits = 2,
      col.names = c("Tribunal", "n", "Média", "Desvio-Padrão", 
                   "Variância", "CV")) %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

# Teste F para igualdade de variâncias
var_test_tribunal <- var.test(tempo ~ tribunal, data = processamento)
print("Teste F para Igualdade de Variâncias:")
print(var_test_tribunal)

# Teste de Welch (variâncias diferentes)
t_test_welch <- t.test(tempo ~ tribunal, 
                      data = processamento, 
                      var.equal = FALSE,  # Welch
                      alternative = "two.sided")

print("Teste t de Welch (Variâncias Diferentes):")
print(t_test_welch)

# Comparando os dois testes
t_test_pooled_trib <- t.test(tempo ~ tribunal, 
                           data = processamento, 
                           var.equal = TRUE)

comparacao <- data.frame(
  Teste = c("Pooled", "Welch"),

print("Comparação dos Testes:")

p_tribunais <- processamento %>%

  stat_summary(fun = mean, geom = "point", 
               shape = 23, size = 4, fill = "white", stroke = 1.5) +

       subtitle = paste("Welch t-test: t =", round(t_test_welch$statistic, 2),
                       ", df =", round(t_test_welch$parameter, 1),
                       ", p =", round(t_test_welch$p.value, 4)),
       x = "Tribunal", 
       y = "Tempo (dias)",
       caption = "Violin plot mostra densidade; losango = média") +
  scale_fill_manual(values = c("lightgreen", "lightpink")) +
  theme(legend.position = "none")

print(p_tribunais)
```

17.4 21.3 Intervalos de Confiança para a Diferença de Médias

17.4.1 Intervalo de Confiança (Variâncias Iguais)

\[(\bar{x_1} - \bar{x_2}) \pm t^*_{df} \cdot s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}\]

17.4.2 Intervalo de Confiança (Variâncias Diferentes)

\[(\bar{x_1} - \bar{x_2}) \pm t^*_{df} \cdot \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}\]

Code
```{r intervalos-confianca}
# Exemplo: Efetividade de dois programas de reabilitação criminal

set.seed(101)

# Programa A: Terapia cognitivo-comportamental
programa_a <- rnorm(30, mean = 12.5, sd = 4.2)  # meses sem reincidência

  meses_sem_reincidencia = c(programa_a, programa_b),
  programa = factor(rep(c("TCC", "Tradicional"), c(30, 28)))
)

# Análise exploratória
stats_reab <- reabilitacao %>%
  group_by(programa) %>%
  summarise(
    n = n(),
    media = mean(meses_sem_reincidencia),
    dp = sd(meses_sem_reincidencia),
    mediana = median(meses_sem_reincidencia),
    q1 = quantile(meses_sem_reincidencia, 0.25),
    q3 = quantile(meses_sem_reincidencia, 0.75),
    .groups = "drop"
  )

kable(stats_reab, digits = 2, 
      caption = "Estatísticas dos Programas de Reabilitação") %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

# Teste de igualdade de variâncias
var_test_reab <- var.test(meses_sem_reincidencia ~ programa, data = reabilitacao)
print(paste("Teste F - valor p:", round(var_test_reab$p.value, 4)))

# Como p > 0.05, assumimos variâncias iguais
# Teste t pooled com IC
t_test_reab <- t.test(meses_sem_reincidencia ~ programa, 
                     data = reabilitacao, 
                     var.equal = TRUE,
                     conf.level = 0.95)

print("Teste t Pooled com Intervalo de Confiança (95%):")
print(t_test_reab)

# Extraindo informações do IC
ic_lower <- t_test_reab$conf.int[1]
ic_upper <- t_test_reab$conf.int[2]
diferenca <- t_test_reab$estimate[1] - t_test_reab$estimate[2]

cat("\nInterpretação do Intervalo de Confiança:\n")
cat("Diferença estimada (TCC - Tradicional):", round(diferenca, 2), "meses\n")

cat("Como o IC não contém 0, há evidência de diferença significativa.\n")

niveis_conf <- c(0.90, 0.95, 0.99)
resultados_ic <- map_dfr(niveis_conf, function(nivel) {
  test_temp <- t.test(meses_sem_reincidencia ~ programa, 
                     data = reabilitacao, 
                     var.equal = TRUE,
                     conf.level = nivel)
  
  tibble(
    Confianca = paste0(nivel * 100, "%"),
    Limite_Inferior = test_temp$conf.int[1],
    Limite_Superior = test_temp$conf.int[2],
    Largura = test_temp$conf.int[2] - test_temp$conf.int[1]
  )
})

print("Intervalos de Confiança para Diferentes Níveis:")
kable(resultados_ic, digits = 3) %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

# Visualização dos resultados
p_reab1 <- ggplot(reabilitacao, aes(x = programa, y = meses_sem_reincidencia, 
                                   fill = programa)) +
  geom_boxplot(alpha = 0.7, width = 0.6) +
  geom_jitter(width = 0.2, alpha = 0.6, size = 2) +
  stat_summary(fun = mean, geom = "point", 
               shape = 23, size = 4, fill = "white", stroke = 1.5) +
  labs(title = "Meses sem Reincidência por Programa",
       x = "Programa de Reabilitação", 
       y = "Meses sem Reincidência") +
  scale_fill_manual(values = c("lightblue", "lightcoral")) +
  theme(legend.position = "none")

# Gráfico do intervalo de confiança
p_reab2 <- ggplot(resultados_ic, aes(x = Confianca, y = (Limite_Inferior + Limite_Superior)/2)) +
```

17.5 21.4 Robustez e Diagnósticos

17.5.1 Verificação das Suposições

Code
```{r diagnosticos}
# Função para diagnósticos completos
diagnosticar_teste_t <- function(dados, variavel, grupo) {
  
  # Separando os grupos
  grupo1 <- dados[dados[[grupo]] == unique(dados[[grupo]])[1], variavel]
  grupo2 <- dados[dados[[grupo]] == unique(dados[[grupo]])[2], variavel]
  
  # 1. Testes de normalidade
  shapiro1 <- shapiro.test(grupo1)
  shapiro2 <- shapiro.test(grupo2)
  
  # 2. Teste de igualdade de variâncias
  var_test <- var.test(dados[[variavel]] ~ dados[[grupo]])
  
  # 3. Teste de Levene (mais robusto)
  levene_test <- car::leveneTest(dados[[variavel]] ~ dados[[grupo]])
  
  # Resultados
  list(
    normalidade_grupo1 = shapiro1,
    normalidade_grupo2 = shapiro2,
    var_test_f = var_test,
    levene_test = levene_test
  )
}
```

17.6 21.5 Tamanho do Efeito e Poder Estatístico

17.6.1 Tamanho do Efeito (d de Cohen)

O d de Cohen mede a magnitude da diferença em termos de desvios-padrão:

\[d = \frac{\mu_1 - \mu_2}{\sigma_{pooled}}\]

Interpretação:

  • d = 0.2: efeito pequeno
  • d = 0.5: efeito médio
  • d = 0.8: efeito grande
Code
```{r tamanho-efeito}
# Calculando d de Cohen para o exemplo de reabilitação
library(effsize)

# d de Cohen
cohen_d <- cohen.d(meses_sem_reincidencia ~ programa, data = reabilitacao)
print("d de Cohen:")
print(cohen_d)

# Cálculo manual
media_tcc <- mean(reabilitacao$meses_sem_reincidencia[reabilitacao$programa == "TCC"])
media_trad <- mean(reabilitacao$meses_sem_reincidencia[reabilitacao$programa == "Tradicional"])
dp_tcc <- sd(reabilitacao$meses_sem_reincidencia[reabilitacao$programa == "TCC"])
dp_trad <- sd(reabilitacao$meses_sem_reincidencia[reabilitacao$programa == "Tradicional"])

# Desvio-padrão pooled
n_tcc <- sum(reabilitacao$programa == "TCC")
n_trad <- sum(reabilitacao$programa == "Tradicional")
dp_pooled <- sqrt(((n_tcc-1)*dp_tcc^2 + (n_trad-1)*dp_trad^2) / (n_tcc + n_trad - 2))

d_manual <- (media_tcc - media_trad) / dp_pooled

cat("\nCálculo Manual do d de Cohen:\n")
cat("Média TCC:", round(media_tcc, 2), "\n")
cat("Média Tradicional:", round(media_trad, 2), "\n")
cat("Desvio-padrão pooled:", round(dp_pooled, 2), "\n")
cat("d de Cohen:", round(d_manual, 3), "\n")

# Interpretação
interpretar_cohen_d <- function(d) {
  if (abs(d) < 0.2) return("Efeito trivial")
  else if (abs(d) < 0.5) return("Efeito pequeno")
  else if (abs(d) < 0.8) return("Efeito médio")
  else return("Efeito grande")
}

cat("Interpretação:", interpretar_cohen_d(d_manual), "\n")
```

17.8 21.7 Resumo e Diretrizes Práticas

17.8.1 Fluxograma de Decisão

ImportantEscolha do teste adequado

O pesquisador é o responsável pela escolha adequada dos testes de significância: TScontraHo!


=== FLUXOGRAMA PARA COMPARAÇÃO DE DUAS MÉDIAS ===

1. VERIFICAR PRESSUPOSTOS
   ├─ Normalidade (Shapiro-Wilk, Q-Q plots)
   ├─ Independência (design do estudo)
   └─ Igualdade de variâncias (Teste F, Levene)

2. ESCOLHER TESTE
   ├─ Se NORMAL + VARIÂNCIAS IGUAIS → t pooled
   ├─ Se NORMAL + VARIÂNCIAS DIFERENTES → Welch t-test  
   ├─ Se NÃO NORMAL → Mann-Whitney
   └─ Se INCERTO → Bootstrap

3. INTERPRETAR RESULTADOS
   ├─ Valor-p < α → Diferença significativa
   ├─ Intervalo de confiança
   ├─ Tamanho do efeito (d de Cohen)
   └─ Relevância prática

4. RELATAR RESULTADOS
   ├─ Estatísticas descritivas
   ├─ Teste utilizado e justificativa
   ├─ Resultados (estatística, p-valor, IC)
   └─ Conclusão em contexto

17.8.3 Interpretação de Resultados

Code
```{r interpretacao-resultados}
# Função para interpretação automatizada
interpretar_teste_duas_medias <- function(teste_resultado, alpha = 0.05, contexto = "") {
  
  p_valor <- teste_resultado$p.value
  ic <- teste_resultado$conf.int
  
  cat("=== INTERPRETAÇÃO DOS RESULTADOS ===\n")
  cat("Contexto:", contexto, "\n\n")
  
  # Decisão estatística
  if (p_valor < alpha) {
    cat("DECISÃO: Rejeitar H₀ (p-valor =", round(p_valor, 4), "< α =", alpha, ")\n")
    cat("CONCLUSÃO ESTATÍSTICA: Há evidência de diferença significativa entre os grupos.\n")
  } else {
    cat("DECISÃO: Não rejeitar H₀ (p-valor =", round(p_valor, 4), "≥ α =", alpha, ")\n")
    cat("CONCLUSÃO ESTATÍSTICA: Não há evidência suficiente de diferença entre os grupos.\n")
  }
  
  # Intervalo de confiança
  cat("\nINTERVALO DE CONFIANÇA", paste0((1-alpha)*100, "%"), "para a diferença:\n")
  cat("[", round(ic[1], 3), ";", round(ic[2], 3), "]\n")
  
  if (0 >= ic[1] && 0 <= ic[2]) {
    cat("O IC contém 0, consistente com não rejeição de H₀.\n")
  } else {
    cat("O IC não contém 0, consistente com rejeição de H₀.\n")
  }
  
  cat("\nIMPLICAÇÕES PRÁTICAS:\n")
  cat("A diferença estimada entre os grupos é de", round(teste_resultado$estimate[1] - teste_resultado$estimate[2], 3), "unidades.\n")
}

# Aplicando ao exemplo de salários
cat("Exemplo: Análise Salarial por Gênero\n")
interpretar_teste_duas_medias(t_test_sal, contexto = "Diferença salarial entre gêneros")
```

NoteConsiderações Finais

A comparação de duas médias é uma ferramenta fundamental em estatística aplicada ao direito e políticas públicas. A escolha adequada do método estatístico, verificação cuidadosa dos pressupostos e interpretação contextualizada dos resultados são essenciais para conclusões válidas e úteis.

Pontos-chave: - Sempre verificar pressupostos antes de aplicar o teste - O teste de Welch é mais robusto quando há dúvida sobre igualdade de variâncias - Reportar tanto significância estatística quanto relevância prática - Considerar métodos alternativos quando pressupostos são violados
