20  Tabela de Dupla Entrada: Pesquisa Gallup sobre Hábitos de Fumantes

20.1 VERIFIQUE SUAS HABILIDADES

Uma Pesquisa Gallup de 2017 perguntou a uma amostra de fumantes várias questões sobre seus hábitos de fumar e crenças sobre o tabagismo.1 Duas das questões na pesquisa eram: “Em geral, quão prejudicial para os adultos você considera o tabagismo passivo – muito prejudicial, pouco prejudicial, não muito prejudicial ou nem um pouco prejudicial?” e “Quantos maços de cigarros você fuma por dia?” A seguir, encontra-se uma tabela de dupla entrada dos resultados.

Code
```{r}
#| label: tbl-fumantes-gallup
#| tbl-cap: "Relação entre percepção de prejuízo do tabagismo passivo e quantidade de cigarros fumados por dia"

# Criar a matriz de dados
dados_fumantes <- matrix(
  c(797, 228, 63,
    777, 446, 120,
    263, 179, 69,
    155, 139, 63),
  nrow = 4,
  byrow = TRUE
)

# Adicionar nomes às linhas e colunas
rownames(dados_fumantes) <- c(
  "Muito prejudicial",
  "Pouco prejudicial",
  "Não muito prejudicial",
  "Nem um pouco prejudicial"
)

colnames(dados_fumantes) <- c(
  "Menos de um maço",
  "Um maço",
  "Mais de um maço"
)

# Calcular totais
totais_linha <- rowSums(dados_fumantes)
totais_coluna <- colSums(dados_fumantes)
total_geral <- sum(dados_fumantes)

# Criar tabela completa com totais
tabela_completa <- cbind(dados_fumantes, Total = totais_linha)
tabela_completa <- rbind(tabela_completa, Total = c(totais_coluna, total_geral))

# Exibir tabela formatada
kable(tabela_completa,
      align = "c",
      caption = NULL) %>%
  kable_styling(
    bootstrap_options = c("striped", "hover", "condensed"),
    full_width = FALSE,
    position = "center"
  ) %>%
  add_header_above(c(" " = 1, "Cigarros por dia" = 3, " " = 1)) %>%
  row_spec(0, bold = TRUE, background = "#f0f0f0") %>%
  row_spec(5, bold = TRUE, background = "#e0e0e0") %>%
  column_spec(1, bold = TRUE, background = "#f9f9f9") %>%
  column_spec(5, bold = TRUE, background = "#f0f0f0")
```

20.2 Questões

20.2.1 25.20 O percentual de fumantes na amostra que fumam mais de um maço por dia é

Code
```{r}
#| label: calculo-25-20

# Total de fumantes que fumam mais de um maço por dia
mais_um_maco <- sum(dados_fumantes[, "Mais de um maço"])

# Total de fumantes na amostra
total_fumantes <- total_geral

# Percentual
percentual_mais_um_maco <- (mais_um_maco / total_fumantes) * 100

cat("Total de fumantes que fumam mais de um maço por dia:", mais_um_maco, "\n")
cat("Total de fumantes na amostra:", total_fumantes, "\n")
cat("Percentual:", round(percentual_mais_um_maco, 2), "%\n")
```
Total de fumantes que fumam mais de um maço por dia: 315 
Total de fumantes na amostra: 3299 
Percentual: 9.55 %

Cálculo detalhado:

\[ \text{Percentual} = \frac{\text{Total que fumam mais de um maço}}{\text{Total de fumantes}} \times 100 \]

\[ \text{Percentual} = \frac{63 + 120 + 69 + 63}{3299} \times 100 = \frac{315}{3299} \times 100 = 9.55\% \]

Alternativas:

  1. 32,98%
  2. 9,55%
    (c) 9.55% ✓

Resposta: (b) 9,55%

20.5 Interpretação

A tabela de dupla entrada mostra a relação entre a percepção dos fumantes sobre os prejuízos do tabagismo passivo e a quantidade de cigarros que eles fumam diariamente. Alguns pontos importantes:

  1. Maioria fuma menos de um maço: A maior parte dos fumantes (1992 ou 60.4%) fuma menos de um maço por dia.

  2. Percepção predominante: A percepção mais comum é que o tabagismo passivo é “muito prejudicial” (1088 fumantes ou 33%) ou “pouco prejudicial” (1343 fumantes ou 40.7%).

  3. Fumantes pesados: Apenas 9.55% dos fumantes na amostra fumam mais de um maço por dia.

  4. Consistência: Independentemente da quantidade fumada, a maioria dos fumantes reconhece que o tabagismo passivo é prejudicial, o que sugere conscientização sobre os riscos, mesmo entre fumantes.

20.6 Teste quiquadrado: dados_fumantes

Code
```{r}
# Teste Qui-Quadrado de Independência
# ====================================

# Realizar o teste qui-quadrado
teste_qui <- chisq.test(dados_fumantes)

# Exibir resultados completos
print(teste_qui)

# Exibir componentes individuais
cat("\n=== RESULTADOS DO TESTE ===\n")
cat("Estatística X² =", round(teste_qui$statistic, 3), "\n")
cat("Graus de liberdade =", teste_qui$parameter, "\n")
cat("Valor-p =", format.pval(teste_qui$p.value, digits = 4), "\n")

# Valores esperados sob H0 (independência)
cat("\n=== VALORES ESPERADOS ===\n")
print(round(teste_qui$expected, 2))

# Resíduos de Pearson
cat("\n=== RESÍDUOS DE PEARSON ===\n")
cat("(Observado - Esperado) / sqrt(Esperado)\n")
print(round(teste_qui$residuals, 2))

# Resíduos padronizados
cat("\n=== RESÍDUOS PADRONIZADOS ===\n")
cat("|r| >= 2: contribuição significativa\n")
cat("|r| >= 3: contribuição muito significativa\n")
print(round(teste_qui$stdres, 2))

# Identificar células com contribuição significativa
significativos <- which(abs(teste_qui$stdres) >= 2, arr.ind = TRUE)
if(nrow(significativos) > 0) {
  cat("\n=== CÉLULAS COM CONTRIBUIÇÃO SIGNIFICATIVA (|r| >= 2) ===\n")
  for(i in 1:nrow(significativos)) {
    linha <- significativos[i, 1]
    coluna <- significativos[i, 2]
    cat(sprintf("%s × %s: r = %.2f\n", 
                rownames(dados_fumantes)[linha],
                colnames(dados_fumantes)[coluna],
                teste_qui$stdres[linha, coluna]))
  }
}

# Conclusão estatística
cat("\n=== CONCLUSÃO ===\n")
if(teste_qui$p.value < 0.05) {
  cat("Rejeitamos H0 (α = 0.05)\n")
  cat("Há evidência de associação significativa entre as variáveis.\n")
} else {
  cat("Não rejeitamos H0 (α = 0.05)\n")
  cat("Não há evidência suficiente de associação entre as variáveis.\n")
}

# Visualização dos resíduos (requer ggplot2 e tidyverse)
if(require(ggplot2) && require(tidyr) && require(tibble)) {
  
  # Criar dataframe para heatmap
  df_residuos <- as.data.frame(teste_qui$stdres) %>%
    rownames_to_column("Percepcao") %>%
    pivot_longer(cols = -Percepcao, 
                 names_to = "Cigarros", 
                 values_to = "Residuo")
  
  # Heatmap dos resíduos padronizados
  p <- ggplot(df_residuos, aes(x = Cigarros, y = Percepcao, fill = Residuo)) +
    geom_tile(color = "white", linewidth = 1) +
    geom_text(aes(label = round(Residuo, 2)), 
              color = ifelse(abs(df_residuos$Residuo) > 1.5, "white", "black"),
              size = 5, fontface = "bold") +
    scale_fill_gradient2(low = "#2166ac", mid = "white", high = "#b2182b",
                         midpoint = 0, limits = c(-5, 5),
                         name = "Resíduo\nPadronizado") +
    labs(title = "Resíduos Padronizados do Teste Qui-Quadrado",
         subtitle = sprintf("X² = %.2f, gl = %d, p %s", 
                           teste_qui$statistic, 
                           teste_qui$parameter,
                           ifelse(teste_qui$p.value < 0.001, "< 0.001", 
                                  paste("=", round(teste_qui$p.value, 4)))),
         x = "Cigarros fumados por dia",
         y = "Percepção sobre tabagismo passivo") +
    theme_minimal(base_size = 12) +
    theme(axis.text.x = element_text(angle = 45, hjust = 1),
          plot.title = element_text(face = "bold", size = 14),
          plot.subtitle = element_text(size = 11),
          legend.position = "right")
  
  print(p)
}
```

Principais componentes do teste:

  • teste_qui$statistic: Estatística X² calculada

  • teste_qui$parameter: Graus de liberdade = (linhas-1) × (colunas-1)

  • teste_qui$p.value: Valor-p do teste

  • teste_qui$expected: Frequências esperadas sob independência

  • teste_qui$residuals: Resíduos de Pearson

  • teste_qui$stdres: Resíduos padronizados (mais úteis para interpretação)

Interpretação dos resíduos padronizados:

  • ∣r∣<2 : não significativo

  • ∣r∣≥2 : contribuição significativa (α = 0.05)

  • ∣r∣≥3 : contribuição muito significativa (α = 0.01)
