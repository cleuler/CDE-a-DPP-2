21  Introdução à Reamostragem

21.1 Objetivos de Aprendizagem

Após leitura do capítulo, você será capaz de:

  1. Calcular a distribuição de permutação e o valor P associado para dados emparelhados ou não emparelhados, quando um número bem pequeno de sujeitos está associado a dois grupos de tratamento.

  2. Usar programa para simular a distribuição de permutação para dados emparelhados ou não emparelhados, quando sujeitos estão associados a dois grupos de tratamento.

  3. Usar programa para gerar muitas amostras bootstrap e usar a distribuição bootstrap para aproximar a distribuição amostral de uma estatística.

  4. Calcular o intervalo de confiança bootstrap percentílico para o parâmetro correspondente a partir da distribuição bootstrap para uma estatística.

21.2 Reamostragem: Testes de Permutação e Bootstrap

Distribuições amostrais fornecem uma importante ferramenta para a inferência estatística.

Elas respondem à questão: “O que aconteceria em muitas amostras?”

Quando nossos dados são medidas quantitativas de uma única população, respondemos a essa pergunta supondo, primeiro, que nossos dados sejam umaamostra aleatória simples de uma população Normal.

Como nossas inferências são sobre médias, elas se baseiam na distribuição amostral de \(\bar{x}\), e, para a construção dessa distribuição amostral, consideramos nossos dados como uma das muitas possíveis amostras que poderíamos ter obtido dessa população Normal.

Sob esse conjunto de suposições, existem fórmulas simples para inferência com base na distribuição t.

Essas inferências são úteis na prática porque são robustas, embora não possamos usar esses métodos para dados fortemente assimétricos, a menos que as amostras sejam grandes.

Fortes valores atípicos também podem afetar nossas conclusões.

21.2.1 Métodos de Reamostragem

As técnicas deste capítulo nos permitem enfraquecer algumas dessas suposições.

Os testes de permutação e o bootstrap são exemplos de métodos de reamostragem.

NoteReamostragem

Na reamostragem, usamos as observações individuais em uma amostra para a construção da distribuição amostral relevante.

Sem outras suposições sobre as populações das quais os dados são extraídos, a construção dessas distribuições amostrais é específica para os dados amostrais observados e requer um programa para automatizar a computação exigida em todos os exemplos, exceto os menores.

21.2.1.1 Testes de Permutação

Os testes de permutação são úteis para os experimentos planejados nos quais os tratamentos são associados aleatoriamente aos sujeitos.

Eles usam a aleatorização no planejamento do experimento para a construção da distribuição amostral, e essas distribuições amostrais são válidas:

  • Sem a suposição de distribuições Normais
  • Para quaisquer tamanhos amostrais

No entanto, não há mais fórmulas simples para a estatística de teste, e é necessário um programa, exceto em situações com tamanhos amostrais muito pequenos.

21.2.1.2 Métodos Bootstrap

Os métodos bootstrap também nos permitem enfraquecer algumas das suposições tradicionais, e podemos fazer inferências válidas sobre a população da qual os dados são uma amostra aleatória, independentemente da forma da distribuição populacional.

Além disso, o bootstrap é um método muito geral que nos permite fazer inferências válidas sobre parâmetros diferentes de médias, sem modificações na técnica básica do bootstrap.

22 Aleatorização em Experimentos

22.1 Experimento Comparativo Aleatorizado - ECA

Um experimento que usa tanto a comparação de dois ou mais tratamentos quanto a associação aleatória dos sujeitos aos tratamentos é chamado de experimento comparativo aleatorizado.

Não fazemos quaisquer suposições sobre como os sujeitos foram selecionados para participar do experimento e apenas usamos a aleatorização na associação dos sujeitos aos tratamentos.

Embora não tenhamos feito quaisquer suposições, exceto a de associação aleatória dos sujeitos aos tratamentos, nossas inferências exigem uma suposição adicional:

Se não houver nenhuma diferença nos efeitos do novo tratamento e do placebo sobre a perda de peso, então o peso perdido por qualquer sujeito deve ser o mesmo, independentemente de o sujeito ter recebido o novo tratamento ou um placebo.

Enfatizamos que, se os efeitos do novo tratamento e do placebo sobre a perda de peso não diferissem, teríamos observado essas mesmas perdas de peso, independentemente de quem foi associado ao tratamento e quem foi associado ao placebo. Em particular, supomos que as distribuições das perdas de peso para os dois grupos sejam idênticas.

22.2 EXEMPLO 32.1: Um Planejamento Completamente Aleatorizado

22.2.1 Descrição do Experimento

Suponha que você tenha: - Três homens: Ari, Luís e Troy - Três mulheres: Ana, Deb e Hui

Objetivo: Três dos seis sujeitos devem ser associados de maneira completamente aleatória a um novo tratamento experimental de perda de peso e três a um placebo.

Existem 20 maneiras possíveis de seleção de três desses sujeitos para o grupo de tratamento:

Com um planejamento completamente aleatorizado, cada um desses 20 possíveis grupos de tratamento é igualmente provável; assim, cada um tem probabilidade de 1/20 ser o real grupo associado ao tratamento.

22.3 EXEMPLO 32.2: Distribuição de Permutação

Usaremos a perda média de peso dos que receberam o tratamento menos a perda média de peso dos que receberam o placebo para o teste da hipótese nula.

22.3.1 Cálculo da Diferença nas Médias

Se não há diferença entre o novo tratamento e o placebo, a diferença observada nas médias é o resultado do “acaso da extração” – ou seja, quais três sujeitos foram, por acaso, associados ao grupo de tratamento.

Exemplo de cálculo:

Se Ari, Luís e Troy são associados ao grupo de tratamento:

- Perda média tratamento: \((2 + 15 + 8)/3 = 8,33\) libras

- Perda média placebo (Ana, Deb, Hui): \((1 + 12 + 9)/3 = 7,33\) libras
- Diferença: \(8,33 - 7,33 = 1,00\) libra

22.3.2 Distribuição de Permutação

Ordenando as diferenças nas perdas médias de peso da menor para a maior, com probabilidade \(1/20 = 0,05\) para cada:

Perda de peso -8,33 -7,67 -5,67 -3,67 -3,00 -1,67 -1,00 -0,33
Probabilidade 0,05 0,05 0,05 0,10 0,05 0,05 0,10 0,05
Perda de peso 0,33 1,00 1,67 3,00 3,67 5,67 7,67 8,33
Probabilidade 0,05 0,10 0,05 0,05 0,10 0,05 0,05 0,05
Code
```{r exemplo-32-2-permutacao}
# Calcular todas as 20 permutações possíveis
perda_peso <- c(2, 15, 8, 1, 12, 9)

# Gerar todas as combinações de 3 sujeitos para tratamento
todas_combinacoes <- combn(1:6, 3)
n_permutacoes <- ncol(todas_combinacoes)

# Calcular diferença de médias para cada permutação
diferencas <- numeric(n_permutacoes)

for(i in 1:n_permutacoes) {
  tratamento_idx <- todas_combinacoes[, i]
  controle_idx <- setdiff(1:6, tratamento_idx)
  
  media_tratamento <- mean(perda_peso[tratamento_idx])
  media_controle <- mean(perda_peso[controle_idx])
  
  diferencas[i] <- media_tratamento - media_controle
}

# Criar tabela de distribuição de permutação
dist_permutacao <- data.frame(
  Diferenca = round(diferencas, 2)
) %>%
  group_by(Diferenca) %>%
  summarise(Frequencia = n(), .groups = "drop") %>%
  mutate(Probabilidade = Frequencia / n_permutacoes) %>%
  arrange(Diferenca)

kable(dist_permutacao, 
      caption = "Distribuição de Permutação Completa",
      col.names = c("Diferença nas Médias", "Frequência", "Probabilidade")) %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

# Gráfico de pontos da distribuição
ggplot(data.frame(Diferenca = diferencas), aes(x = Diferenca)) +
  geom_dotplot(binwidth = 0.5, fill = "steelblue", color = "black") +
  geom_vline(xintercept = 3.67, color = "red", linetype = "dashed", size = 1) +
  labs(
    title = "Distribuição de Permutação - Diferença nas Médias",
    subtitle = "Linha vermelha: diferença observada (Troy, Deb, Hui no tratamento)",
    x = "Diferença nas perdas médias de peso (libras)",
    y = "Densidade"
  ) +
  theme_minimal()

# Calcular valor P para diferença observada de 3.67
diferenca_observada <- 3.67
valor_p <- mean(abs(diferencas) >= abs(diferenca_observada))
cat("\nDiferença observada:", diferenca_observada, "libras")
cat("\nValor P (bilateral):", valor_p)
```

22.3.3 Interpretação

O que concluiríamos se Troy, Deb e Hui fossem destinados ao tratamento? A diferença seria 3,67 libras.

A chance de observar uma diferença tão grande quanto, ou maior que 3,67, é 0,25 (valor P).

TipInterpretação do Valor P

Um efeito que tem 0,25 de probabilidade de ocorrer por acaso não é considerado estatisticamente significante.

Os tamanhos amostrais são muito pequenos para que todos os dados, exceto os mais extremos, alcancem significância estatística.

23 Testes de Permutação

23.1 Suposições para um Teste de Permutação Simples

  1. Os tratamentos são associados às unidades experimentais com base em um planejamento aleatorizado. O método de aleatorização é importante quando avaliamos a significância do resultado.

  2. Testamos a hipótese nula de nenhuma diferença no efeito dos tratamentos sobre uma resposta.

  3. Se não há diferença nos efeitos dos tratamentos, então a resposta medida para uma unidade será a mesma, independentemente do tratamento recebido.

23.2 Procedimento de Teste de Permutação Simples

Para realizar testes de permutação da hipótese nula de nenhuma diferença nos efeitos dos tratamentos:

  1. Determine a probabilidade de todas as possíveis associações dos tratamentos às unidades experimentais.

  2. Para cada associação possível, calcule o valor da estatística sob a hipótese nula.

  3. A probabilidade de cada possível associação e o valor da estatística para aquela associação é a distribuição de permutação da estatística sob a hipótese nula.

  4. Essa distribuição de permutação determina o valor P dos dados, resultante da associação realmente obtida.

23.3 EXEMPLO 32.3: Teste de Permutação para Dados Emparelhados

23.3.1 Contexto: Repelentes de Insetos

Os voluntários deixam seus braços na gaiola por cinco minutos.

Opracionalização do conceito de falha: considerase que o repelente falhou se um voluntário é picado duas ou mais vezes durante um período de cinco minutos, ou pelo menos uma vez nos períodos de cinco minutos durante duas sessões consecutivas de uma hora.

A variável resposta é o número de sessões de uma hora até que um repelente falhe.

Pergunta de pesquisa: Qual repelente é mais eficaz: DEET (15%) ou óleo de eucalipto-limão?

Planejamento experimental:

- 4 voluntários (Erin, Raj, Todd e Wanda)

- Cada voluntário recebe um repelente no braço esquerdo e outro no direito

- Aleatorização determina qual braço recebe qual repelente

- Resposta: número de horas até a falha do repelente

Dados coletados:

Os quatro voluntários são Erin, Raj, Todd e Wanda. Eis os números de horas até a falha para os dois repelentes.

Sujeito Erin Raj Todd Wanda
DEET 5 7 4 4
Óleo de eucalipto-limão 8 7 6 7
Diferença (DEET - Óleo) -3 0 -2 -3
Code
```{r exemplo-32-3-dados}
# Dados do Exemplo 32.3 - Repelentes de insetos
repelentes <- data.frame(
```

23.3.2 Análise de Permutação

Este é um planejamento de dados emparelhados, com as duas observações para cada sujeito formando os pares.

Hipótese Nula: Se não houvesse diferença nos efeitos dos dois tratamentos, teríamos obtido as mesmas respostas independentemente de qual braço recebeu qual repelente.

Para cada sujeito, há duas possíveis maneiras de associar os repelentes aos braços (esquerdo/direito). Com 4 sujeitos, temos \(2^4 = 16\) possíveis associações.

23.3.3 Distribuição de Permutação

Considerando as magnitudes das diferenças como números fixos (0, 2, 3, 3), com os sinais determinados pela aleatorização:

Diferença média -2,0 -1,0 -0,5 0,5 1,0 2,0
Probabilidade 0,125 0,125 0,250 0,250 0,125 0,125

23.3.4 Conclusão

A diferença média observada foi -2,0.

Valor P (bilateral): Probabilidade de obter valores tão extremos quanto ±2,0 = \(0,125 + 0,125 = 0,250\)

NoteInterpretação

Um valor P de 0,250 não é considerado estatisticamente significante. Não há evidência suficiente de diferença entre os dois repelentes.

Note que com apenas 4 sujeitos, não é possível demonstrar significância estatística no nível de 0,1, mesmo com o resultado mais extremo possível.

24 Testes de Permutação com Programa

Para amostras maiores, o número de permutações possíveis cresce rapidamente, tornando impraticável enumerar todas. Usamos simulação para aproximar a distribuição de permutação.

24.1 EXEMPLO 32.4: Perda de Peso com Programa

Usando os mesmos dados do Exemplo 32.1, mas agora com 10.000 permutações simuladas:

  • A distribuição simulada concorda bem com a distribuição exata (20 permutações)
  • Valor P empírico: 0,2537 (muito próximo do valor teórico de 0,25)
  • Barras sombreadas incluem diferenças ≥ 3,67
ImportantNúmero de Simulações

1.000 simulações geralmente são suficientes para a maioria dos propósitos. Se maior precisão for necessária, use mais simulações (e.g., 10.000).

100 simulações tendem a ser muito poucas, produzindo resultados imprecisos que variam consideravelmente entre simulações.

24.2 EXEMPLO 32.6: Dor Compartilhada e Vínculo

24.2.1 Contexto da Pesquisa

Pergunta: O compartilhamento de uma experiência dolorosa em pequenos grupos leva a maior vínculo entre os membros?

Participantes: 54 estudantes universitários em South Wales

Grupos:

- Grupo com dor (n=27): Submergir mãos em água gelada; agachamento contra parede

- Grupo sem dor (n=27): Água à temperatura ambiente; equilíbrio em um pé

Medida: Escore de vínculo (média de 7 afirmações em escala de 1-5)

24.2.2 Resultados

Comparação de médias:

- Diferença observada: 0,577

- Valor P (10.000 permutações): 0,0231

- Teste t de duas amostras: p = 0,0240

Comparação de medianas (mais robusta):

- Diferença observada: 0,86

- Valor P: 0,0108

TipEscolha da Estatística

A mediana é preferível quando há valores atípicos. Neste caso, o grupo da dor tinha dois valores atípicos baixos, tornando a comparação de medianas mais apropriada.

25 Métodos Bootstrap

25.1 Conceitos Fundamentais

25.1.1 Amostragem com Reposição

NoteDefinição

Para a amostragem com reposição de uma população, depois que uma observação é selecionada, retorne-a para a população antes que a próxima observação seja extraída. Assim, a mesma observação pode ser selecionada múltiplas vezes.

25.1.2 Amostras Bootstrap

Amostras bootstrap são geradas pela amostragem com reposição a partir de uma amostra real observada. Consideramos a amostra original como representante da população.

25.2 EXEMPLO 32.9: Distribuição Bootstrap da Média

25.2.1 Dados: Tempos de Viagem na Carolina do Norte

15 trabalhadores, tempos em minutos.

Média original: 25,33 minutos.

25.2.2 Processo Bootstrap

  1. Gerar 1.000 amostras bootstrap (amostragem com reposição dos 15 tempos)
  2. Calcular a média de cada amostra bootstrap
  3. A distribuição dessas 1.000 médias é a distribuição bootstrap

25.2.3 Resultados

Distribuição bootstrap:

- Média: 25,55 minutos

- Desvio-padrão (erro-padrão bootstrap): 4,22 minutos

- Forma: Aproximadamente Normal com leve assimetria à direita

Comparação com teoria:

- Erro-padrão teórico: \(s/\sqrt{n} = 16,969/\sqrt{15} = 4,38\)

- Muito próximo do erro-padrão bootstrap!

27 Considerações Práticas

27.1 Quando Usar Bootstrap

Vantagens:

- Não requer suposição de Normalidade

- Funciona para diversos parâmetros (média, mediana, razão, etc.)

- Apropriado para distribuições assimétricas

Limitações:

1. Requer tamanho amostral moderado a grande

2. Funciona melhor para estatísticas suaves (média) do que para medianas em amostras pequenas

3. Algumas estatísticas podem ter viés que requer correção

27.2 Número de Reamostras

  • 1.000 simulações: Geralmente suficiente
  • 10.000 simulações: Para maior precisão
  • 100 simulações: Muito poucas (resultados instáveis)

```{r exercicio-32-1-completo}
  idx_mao <- combinacoes[, i]

  group_by(Diferenca) %>%
  summarise(Frequencia = n(), .groups = "drop") %>%
  mutate(Probabilidade = Frequencia / n_comb) %>%
  arrange(Diferenca)

print(dist_perm_ex1)

# (c) Valor P
dif_obs <- mean(c(360, 400, 420)) - mean(c(370, 320, 390))
valor_p <- mean(abs(diferencas_ex1) >= abs(dif_obs))
cat("\nDiferença observada:", dif_obs)
```
